# 🚗 RoadRescue — Roadside Vehicle Assistance & Mechanic Booking Platform

RoadRescue is a web-based application that allows customers to request roadside vehicle assistance and helps administrators manage service bookings.

## 🌐 Live Website

**[Click here to open RoadRescue](https://roadrescue-meghana.netlify.app/)**

## 📂 GitHub Repository

**[View RoadRescue Source Code](https://github.com/bottemeghana-hash/RoadRescue)**

## ✨ Features

- Customer roadside assistance booking
- Admin login
- View customer bookings
- Update booking statuses
- Store booking information in MongoDB
- Responsive user interface

## 🛠️ Technologies Used

- **Frontend:** React.js, HTML, CSS, JavaScript
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Frontend Hosting:** Netlify
- **Backend Hosting:** Render
